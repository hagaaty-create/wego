خطوات رفع السيستم على GitHub & Vercel مجاناً 100%

  1. إنشاء مستودع GitHub جديد:
    ادخل على GitHub.com/new وأنشئ مستودعاً باسم wego-barber-system.
  2. رفع الكود من جهازك:
    افتح التيرمينال (PowerShell) في مجلد المشروع ونفذ الأوامر التالية: 
    git init
git add .
git commit -m "Initial WEGO Barber System with Firebase"
git branch -M main
git remote add origin YOUR_GITHUB_REPO_URL
git push -u origin main
  3. الربط والنشر على Vercel بنقرة واحدة:
    افتح موقع Vercel.com/new وسجل بحساب GitHub الخاص بك.
  4. اختر مشروع wego-barber-system وانقر Deploy! سينطلق موقعك فوراً مع رابط مجاني ومدى الحياة (https://wego-barber.vercel.app).
