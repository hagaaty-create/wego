# WEGO Barber Shop System ✂️

سيستم إدارة وحسابات محل حلاقة متكامل مبني على HTML/CSS/JS النقي بدون فريموركات مع ربط ذكي بقواعد بيانات Firebase (Firestore).

## مميزات النظام (الإصدار الجديد):
- **توفير كوتة الفيربيز**: يعتمد التطبيق على بيئة (Offline-First) بحيث يحفظ كافة المعاملات محلياً، ويمكنك مزامنتها مع السحابة بضغطة زر واحدة (Batch Sync) دون استهلاك مفرط للقراءات والكتابة.
- **إدارة كاملة**: خدمات، صنايعية، خصومات، ومصاريف.
- **أزرار الحذف**: أزرار حذف خاصة بكل قسم بالإضافة لزر تنظيف اليومية بالكامل (Purge) لتفريغ مساحة قواعد البيانات وتوفير التكلفة.

## تعليمات الرفع على GitHub و Vercel مجاناً:

1. **GitHub**:
   - قم بإنشاء حساب على [GitHub](https://github.com) إذا لم يكن لديك.
   - قم بإنشاء مستودع جديد (New Repository) وسمه `wego-barber-system`.
   - افتح التيرمينال داخل مجلد المشروع وانسخ الأوامر التالية لنشر المشروع:
     ```bash
     git remote add origin https://github.com/YOUR-USERNAME/wego-barber-system.git
     git branch -M main
     git push -u origin main
     ```

2. **Vercel**:
   - ادخل على [Vercel](https://vercel.com/) وسجل الدخول باستخدام حساب GitHub الخاص بك.
   - اضغط على "Add New Project" واختر مستودع `wego-barber-system` الذي قمت برفعه تواً.
   - اضغط "Deploy". مبروك! سيتم إطلاق المشروع على رابط مجاني مدى الحياة.

## تهيئة Firebase:
لا تحتاج لبرمجة إضافية! بعد إنشاء مشروع في Firebase:
1. اذهب لـ Project Settings.
2. قم بإضافة Web App وانسخ مفاتيح الـ config.
3. داخل السيستم، افتح زر "إعدادات Firebase" من القائمة الجانبية والصق المفاتيح للحفظ.
